# Review Assistance

Версия 0.3.0 открывает локальный учебный merge request и позволяет сохранить подключение к GitLab на macOS.

## Запуск

В рабочей папке проекта выполните `npm run start:dev`. Nest CLI пересобирает TypeScript и перезапускает Electron после успешной компиляции. Команда `npm run dev` запускает тот же режим. На этом Mac уже подготовлена локальная копия Electron в `.local/`. Учебный MR читается с диска.

Для нового checkout сначала установите зависимости и Electron.

```bash
npm ci
npm install --no-save electron@40.10.3
npm run start:dev
```

| Команда | Что делает |
| --- | --- |
| `npm run build` | Собирает TypeScript в `dist/` через Nest CLI. |
| `npm start` | Собирает проект и один раз запускает Electron. |
| `npm run start:dev` | Следит за TypeScript, пересобирает проект и перезапускает Electron. |
| `npm run start:debug` | Запускает режим разработки с отладчиком основного процесса Electron на `127.0.0.1:9229`. |
| `npm run start:prod` | Запускает Electron из готовой сборки после `npm run build`. |

Nest CLI запускает небольшой адаптер, который открывает проект в Electron. Electron загружает общий вход `src/main.ts` из сборки. [Конфигурация Nest CLI](nest-cli.json) · [Адаптер запуска](src/desktop/launch.ts)

## Проверка

1. Нажмите **Открыть пример**. Слева появятся четыре изменённых файла, справа откроется diff первого файла.
2. Откройте `delivery.ts` и найдите замену `>` на `>=` в условии бесплатной доставки. В `delivery.test.ts` показан тест для суммы ровно на пороге.
3. Откройте `states.ts`, чтобы увидеть правку форматирования. В `checkout.yml` проверьте, что подтверждение почты стало обязательным.
4. Нажмите **К началу**, чтобы вернуться на стартовый экран.

Если `fixtures/example.json` недоступен или повреждён, приложение показывает ошибку. После восстановления файла можно повторить открытие без перезапуска.

## Подключение GitLab

1. В GitLab создайте персональный токен с правом `read_api`.
2. В приложении нажмите **GitLab**. Введите основной HTTPS-адрес вашей установки, например `https://gitlab.example.com`, и токен. При необходимости включите VPN.
3. Нажмите **Подключить**. Приложение проверит токен через `/api/v4/user` и покажет имя пользователя.
4. Перезапустите приложение и снова откройте **GitLab**, чтобы проверить сохранение.
5. Нажмите **Отключить**, чтобы удалить токен из Связки ключей. Для замены токена введите новый и нажмите **Обновить подключение**.

Токен хранится как пароль в Связке ключей macOS. Основной процесс отправляет его на указанный HTTPS-адрес, а при перенаправлении останавливается. Если сохранить токен не удалось, кнопка **Только до выхода** позволяет держать его в памяти. Интерфейс показывает, какой режим действует.

Для сборки локального помощника Связки ключей на macOS используются Xcode Command Line Tools. Приложение собирает его при запуске и сохраняет в `.local/bin/`.

## Архитектура

NestJS работает внутри основного процесса Electron. Общая точка входа запускает и закрывает контекст. AppModule подключает модули окна и ревью и регистрирует адаптер между ними. [main.ts](src/main.ts) · [AppModule](src/app.module.ts)

- DesktopModule управляет окном Electron. AppModule передаёт ему пути к странице и preload. [DesktopModule](src/desktop/desktop.module.ts)
- ReviewModule связывает прикладной сервис с источником данных через интерфейс. Адаптер источника читает локальный JSON и разбирает unified diff. [ReviewModule](src/review/review.module.ts) · [Прикладной сервис](src/review/application/open-example-review.ts) · [Адаптер источника](src/review/infrastructure/json-example-review.source.ts)
- Домен описывает MR, файлы и строки diff. Он проверяет уникальность путей и наличие изменений, подсчитывает добавленные и удалённые строки. [Домен ревью](src/review/domain/review.ts)
- Слой представления отображает diff. Кнопка «Открыть пример» отправляет запрос через preload. Адаптер IPC проверяет, что запрос пришёл из основного окна, и вызывает прикладной сервис. [Код представления](src/presentation/review/) · [Обработчик IPC](src/presentation/review/review-ipc.handler.ts)
- [GitLabModule](src/gitlab/gitlab.module.ts) связывает сценарий подключения с адаптерами GitLab HTTP и Связки ключей. Входной адаптер проверяет окно-отправителя и возвращает интерфейсу состояние подключения. [Обработчик GitLab IPC](src/presentation/gitlab/gitlab-ipc.handler.ts)
